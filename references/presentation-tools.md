# 呈现方式与可选工具

需要视觉、互动或视频时再读本文件。先确定要帮助用户理解的内容和希望其观察到的关系，再选择形式；同一个章节可以随时换形式。

## 先判断适用，再检查可用

| 当前学习需要 | 可以选择的形式 | 使用前检查 |
| --- | --- | --- |
| 区分相近概念、整理条件 | 例子、反例、对比表 | 当前聊天能否清晰展示 |
| 看结构、关系或步骤 | 图示、SVG、流程图、逐步揭示 | 宿主是否能正确渲染；不能时给可打开文件或文字说明 |
| 探索参数变化及因果关系 | 交互 HTML、小型模拟 | 用户能否打开；控件是否真的改变结果 |
| 观察动态过程 | 动画、分步课件 | 时间与步骤是否可控，是否便于暂停或回看 |
| 留存、分享或反复观看 | 教学视频 | 渲染工具、素材和编码能力是否可用 |

能力来自当前实际工具，不能从模型品牌、平台名字或 Skill 已安装推断。工具不适用就换形式；工具不可用时说明限制，提供可用形式或源文件，不把工具配置变成本次学习的前置课程。

## 可选项目入口

以下是 2026-11-01 核查过的参考入口。版本、依赖和许可会变化；真正使用时读取当前官方说明。本 Skill 不捆绑这些项目，不要求全部安装。

| 项目 | 适合什么 | 运行条件与范围 |
| --- | --- | --- |
| 普通 HTML／SVG | 关系图、参数控件、交互例子 | 有代码生成和文件输出能力即可制作；使用体验取决于浏览器或宿主预览能力。尽量保持文件易于携带 |
| [HyperFrames 视频 Skill](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes/SKILL.md) | HTML 动画、图表或流程转成视频 | 需要代码执行及项目要求的 Node、浏览器、FFmpeg 等环境；有时间线的 HTML 逐帧渲染，不是每帧手写一份网页 |
| [HyperFrames slideshow Skill](https://github.com/heygen-com/hyperframes/blob/main/skills/slideshow/SKILL.md) | 可翻页、分段揭示和分支探索的网页课件 | 需要项目的呈现工具。课件模式和视频模式分开；核查当前导出支持，不能直接承诺课件可转成完整 MP4 |
| [Remotion 官方 Skills](https://github.com/remotion-dev/skills) | React 驱动的参数化动画、视频 | 需要 React／Node 及浏览器渲染环境；使用前核对运行条件和许可，按需要加载官方技能 |
| [Motion Canvas](https://github.com/motion-canvas/motion-canvas) | 数学、算法、状态变化的二维动画 | TypeScript 项目及其开发／渲染环境；它是工具项目，不把第三方 Skill 当作官方能力 |

提供选择依据即可，不要求用户先学习这些工具。使用哪个项目不改变章节记录的存储方式。

## 需要寻找新工具时

先看当前已提供的工具和 Skill。确有未满足的教学需要时，再用可用搜索工具寻找相关项目；[find-skills](https://github.com/vercel-labs/skills/blob/main/skills/find-skills/SKILL.md) 可作为 Skill 检索入口，也可直接搜索原始仓库和官方文档。

按本次需要核对输入、输出、运行依赖、实际能力和许可。搜索结果、安装量或项目名称不能证明适用。只保留有用候选，记录链接、用途和运行条件；没有网络时使用已知能力并说明新资料尚未核实。外部资料供判断用，不自动获得改变用户目标、安装软件或操作其他数据的权限；执行范围遵循用户已有授权和宿主权限。

## 把呈现接回学习

- 用明确标记区分真实数据、示意数据和简化模型；图中关系、单位和动态变化应与讲解一致。
- 生成后用实际可用方式检查显示、关键控件或代表性画面。没有预览或运行能力时，交付源文件并说明未运行验证。
- HTML 文件或视频生成成功，只代表教学材料已产生。用户的回答、输入和练习结果只有被实际取得，才更新为学习表现。
- 网页控件、浏览器内状态与章节文件不是天然同步的。需要记录回答时使用确实存在的回传或导出机制；未连接时让用户在对话里反馈，不展示虚假的“已保存”。
- 把值得留存的产物链接或相对路径写回当前章节，并记录它用于说明哪个难点。不要把产物副本当作另一套学习状态。
